08 · Cup Localizer NAV2GATHER

USB Webcam 기반 컵 3D 위치 추정 완료

실제 컵 너비(6 cm)와 YOLO Bounding Box 픽셀 너비의 비례 관계로 USB Webcam 기준 3차원 좌표를 계산합니다.

fx = reference_width_px × reference_distance_m / cup_width_m
z = fx × cup_width_m / bbox_width_px
x = (center_x − cx) × z / fx ,   y = (center_y − cy) × z / fy
보정 (Calibration)

실제 너비 6 cm 컵을 USB Webcam 정면 1 m 위치에 두고 30프레임의 Bounding Box 너비를 측정 → 중앙값으로 초점거리(fx)를 확정합니다.

좌표 발행 흐름
/yolo/detections → /cup/point_camera

camera_optical_frame 기준 3차원 좌표

score ≥ 0.50 인 검출 중 최고 신뢰도 컵 1개를 선택하여 좌표 발행 NAV2GATHER

10 · Behavior NAV2GATHER

RViz 수동 Goal → YOLO 기반 자율 목표 생성 완료

사람이 RViz에서 목적지를 찍던 방식에서, 로봇이 스스로 물병을 탐색하고 목표를 생성해 Navigation2로 이동하는 상태 머신 기반 자율 Behavior로 확장했습니다.

기존에는 사람이 RViz에서 목적지를 직접 지정했지만, 이제는 YOLO 인식 결과를 기반으로 로봇이 스스로 목적지를 생성하고 Navigation2로 이동합니다.
5단계 상태 머신 (State Machine)
  • SEARCHING — 제자리 회전하며 bottle 탐색
  • ALIGNING — 화면 중앙으로 각도 정렬
  • COLLECTING — map 좌표 다중 수집·평균화
  • NAVIGATING — goToPose()로 Nav2 자율 이동
  • COOLDOWN — 결과 확인 후 다음 물병 탐색
